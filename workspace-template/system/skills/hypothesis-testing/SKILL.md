---
name: hypothesis-testing
description: Devil's advocate evaluation of a thesis/hypothesis against opposing evidence and logical fallacies before writing.
---
Procedure (be adversarial, not agreeable):
1. Restate thesis as falsifiable claim; list implicit assumptions.
2. Steelman the strongest opposing position.
3. Search for disconfirming empirical evidence (web_search / paper MCP); cite.
4. Audit reasoning: correlation->causation, selection/survivorship bias, confounders, reverse causality, base-rate neglect, overgeneralisation, circularity, cherry-picking, p-hacking, construct validity.
5. Alternative explanations, each with the observation that would distinguish it.
6. Verdict: survives / needs revision / fails; minimal revision that would survive; what evidence would change the verdict.
Output as sections with a table of [objection | severity | evidence | fix].
