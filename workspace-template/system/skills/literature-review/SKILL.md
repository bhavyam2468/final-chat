---
name: literature-review
description: Literature review and research gap analysis across many papers; clustering by method, conflicts, gaps.
---
Never summarise papers one by one. Procedure:
1. Inventory: table [paper | year | question | method | sample/data | key finding | limitation]. Get papers via context files, MCP paper-search (search_arxiv, search_pubmed, search_biorxiv) or web_search.
2. Cluster by methodology (e.g. RCT, observational, simulation, qualitative), then by theoretical stance. Name each cluster; state its shared assumption.
3. Convergence: findings replicated across >=2 clusters (strong evidence).
4. Conflicts: contradictory findings; explain by method, population, measurement, era. Mark unresolved.
5. Gaps: untested populations, methods never applied, variables never measured jointly, stale evidence (>5y), missing replication. Rank by feasibility x impact.
6. Output: cluster map (x-mermaid mindmap or table), conflict table, ranked gap list with a candidate research question each. Save to notes/lit-review-<topic>.md when asked.
If vector MCP (chroma) is enabled, store each paper summary as a document tagged by cluster for later cross-reference.
