# Testing a claim (be adversarial, not agreeable)
1. Restate the thesis as a falsifiable claim; list its implicit assumptions.
2. Steelman the strongest opposing position.
3. Search for disconfirming evidence (web_search / paper MCP); cite it.
4. Audit the reasoning: correlation → causation, selection and survivorship bias, confounders, reverse causality, base-rate neglect, overgeneralisation, circularity, cherry-picking, p-hacking, construct validity.
5. Alternative explanations, each with the observation that would distinguish it.
6. Verdict: survives / needs revision / fails; the minimal revision that would survive; what evidence would change the verdict.
Output sections, with a table of [objection | severity | evidence | fix].
