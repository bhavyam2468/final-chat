# Literature review
Never summarise papers one by one.
1. Inventory: table [paper | year | question | method | sample/data | key finding | limitation]. Papers come from context files, MCP paper servers (search_arxiv, search_pubmed, search_biorxiv) or web_search.
2. Cluster by method (RCT, observational, simulation, qualitative), then by theoretical stance. Name each cluster and its shared assumption.
3. Convergence: findings replicated across ≥2 clusters are the strong evidence.
4. Conflicts: explain by method, population, measurement or era; mark what stays unresolved.
5. Gaps: untested populations, methods never applied, variables never measured together, stale evidence (>5 years), missing replication. Rank by feasibility × impact.
6. Output: cluster map (x-mermaid or table), conflict table, ranked gaps each with a candidate research question. Save to notes/lit-review-<topic>.md when asked.
With a vector MCP enabled, store each paper summary tagged by cluster for cross-reference.
